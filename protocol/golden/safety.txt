# Safety functions: watchdog and failsafe latch, exclusive output groups,
# outputs reset, usbsafe, reset information, pad read-back.
# Specification: docs/30-usb-protocol.md section 12 (pochi-dio) and
# docs/protocol-reference.md section "Safety" (pochi-tools).
# Each case heading `# --- <name> ---` is the test name. The name is exactly
# the heading text, unique in this file, and is the unit in which a replayer
# reports a failure (golden::<name>). The line(s) after a heading describe the case.
# Conventions of this file:
# * MAP A: GP0-GP3 outputs, default 0. MAP B: like A with def=0x8 (GP3 ON by
#   default). MAP C: like A with opol=0x1. MAP D: GP0-GP15 outputs (for the
#   16-group cases).
# * Every `OK` response restarts the watchdog timer at the instant the response
#   is returned (docs/30-usb-protocol.md 12.3). `~ expect_pins` and the other
#   directives do not. A case that observes "still ON just before the deadline"
#   therefore uses `~ expect_pins`, never a request.
# * The watchdog trips at the first poll where now - last_ok >= timeout. The
#   simulator polls at the end of every `~ advance`, before the next request.
# * The USB model starts Configured and DTR starts asserted (see README).
